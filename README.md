# Taste Avenue- Premium Restaurant Demo

React + Vite + Tailwind CSS restaurant website designed as a client-facing demo.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Before showing a real client
Replace the demo brand name, WhatsApp number, menu/prices, address, social links and all food photos with the client's own assets or properly licensed imagery.

The current demo uses public web image URLs for visual presentation only; verify licensing before commercial use.
